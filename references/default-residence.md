# 当前居住地默认范围

用户于2026-09-23明确指定，默认选择以下16个省级地区，彼此为OR（任意一个符合即可）：

湖北、湖南、河南、安徽、江西、江苏、广东、黑龙江、山西、陕西、辽宁、甘肃、福建、贵州、云南、广西。

“福建贵州”按福建、贵州两项处理。页面可能写湖北省等全称，广西可能写广西壮族自治区；按同一行政区域对应，不作包含字符串的模糊匹配，尤其区分山西和陕西。

## 页面操作

- 打开“居住地”，逐一选各省的全省范围；展开省份不等于已选，城市列表中只选省会也不等于全省。读回省级标签或“全部＋省名”证据。
- 保留本轮应选范围，移除上次遗留的其他地区，不沿用演示中的北京、上海等城市。
- 选完确定，再读“当前居住”生效标签；展开折叠内容核对完整范围，不能只看到部分标签就声称全部选中。
- 若页面有数量上限，读取真实上限，按上限将16个省拆成若干轮搜索，其他条件一致，跨轮去重，邀约上限和点数上限合并计算。不能无声删省或把某省换成某市；不因期望工作地弹窗的10项上限就推断居住地也限10项。
- 期望工作地仍是义乌或杭州，与当前居住范围同时满足；不能把这16个省填进顶部期望工作地。
- 自带搜索脚本尚不能填写当前居住地；本默认必须由浏览器工具实际执行并核实，不得只运行脚本后报告完成。涉及当前居住条件时优先全程使用同一个浏览器工具，避免脚本把已选高级条件当未知条件拒绝，也不能为绕过校验清除默认居住范围。浏览器工具不可用时如实报告未完成。

## 每次由顾问选择的年限

年限不设固定默认，不从旧页面、录制或岗位说明自动继承。顾问已在本次任务给出年限时直接使用，不重复问。顾问要求不限时清除；没有给出时收集后再执行。省份范围默认持续生效，顾问明确更改则以本轮要求为准。
