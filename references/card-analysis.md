# 搜索结果卡片分析

搜索后逐人分析，结论形成后才可点击该卡片的 Hi。不打开简历详情，也不点击下载或购买信息。只读当前卡片可见资料；展开被截断的卡片文字仅限仍留在结果页的普通展开控件。被截断、未展示或含糊的信息标为“未展示／待确认”，不能推断不存在。

## 卡片读取方法（实测）

- 卡片容器是 `.item.resume-card`（el-card），**不是**其内部更窄的按钮包裹层——窄层会漏掉“求职意向”（首行，含期望城市）、证书标签和自述职责。读取：`cdp_tools.mjs cards <from> <to>`，或 `document.querySelectorAll('.item.resume-card')`。
- 列表是**虚拟列表**，一次只渲染约 30 张；要看更多需滚动加载后重新读取，且卡片序号会随渲染窗口变化，跨次读取以姓名+年龄+现居城市等稳定特征对齐。
- 卡片文本行序（实测）：求职意向（城市列表）→ 目标职位 → 期望月薪 → （距离）→ 活跃度/回复标签 → 姓名 → 年龄|总年限|学历|现居地 → 逐段经历（时间|公司|职位）→ 院校|专业|学历|标签（211/985/QS）→ 操作按钮 → 证书/技能标签 → 自述职责。
- “距离:>35公里”按现居地计算，仅提示性信息；“总年限”不等于财税年限，按逐段经历判断。

## 判断内容

| 项目 | 读取与判断 |
|---|---|
| 岗位经历 | 对照所选岗位已读取的要求，记录卡片的公司、职位、任职时间、职责摘要。总工作年限不等于财税相关年限；实习不自动计作正式财税工作经验，重叠经历不重复累计。不能仅凭目标职位或搜索关键词认定有对应能力。 |
| 证书 | 记录明确出现的证书名称、级别及状态，例如会计职称、注册会计师、税务师。区分已取得、备考和部分科目通过。卡片自述或标签只是页面证据，不表示已查验证书真伪；“税务”“税务筹划”等技能标签不是证书。 |
| 意向地点 | 读取卡片“求职意向”的完整可见城市，分别标记是否含义乌或杭州、是否明确列出至少两个不同地点。多地点不等于愿意全国调动、出差或搬迁。现居地与期望工作地分开。截断时不擅自补全城市。 |
| 院校背景 | 记录学校、专业、学历及页面明确显示的双一流／211／985标签，注明“页面标注”。页面未给标签则标“未展示”，不能凭印象补标，也不把某一标签自动扩展成另外两个。不同学历经历分别记录，不由院校推断个人能力。 |

证书、多地点意向及院校标签目前是分析项和加分信息，不是额外淘汰门槛；用户尚未明确它们之间的 OR／AND 邀约规则，不自行设成“任一项满足即可邀约”或“必须同时具备”。明确的岗位必要资格和顾问本轮必须要求仍需全部符合，加分信息不能抵消不符合或信息不足。

## 结论与行动

- **推荐邀约**：全部必须条件有明确证据符合，且卡片能支持岗位相关性；记录理由后按浏览器操作规则立即Hi，不逐人询问。
- **待核实**：某项必须条件未展示、内容冲突或被截断，或仅有目标职位而缺乏岗位相关证据。记录缺项并跳过；不打开详情、不发送Hi。只有可选加分项未展示，不因此转为待核实。
- **不匹配**：明确不符合本轮必须条件，记录具体原因并跳过。

简短记录：候选人稳定标识｜岗位经历与证据｜证书及状态｜期望地点与多地点标记｜院校及页面标签｜必须条件核对｜结论及理由｜Hi结果。不输出缺乏依据的匹配百分比，不使用照片、性别、姓名推断能力或稳定性。保留最少必要资料，跨居住地批次按稳定标识去重。

## 判断示例（非真实邀约记录）

卡片显示“杭州、威海”“税收学本科”“985标签”“总经验1年”，仅展示两段短期实习，证书未展示：可记录包含杭州、多地点意向、页面985标签、证书未展示；不能断言有1年正式财税经验。若岗位必须具备1年财税实务经验，结论为待核实并跳过；若岗位明确接受应届或实习经历，且其他必须条件都符合，可推荐邀约。院校标签不改变经验核对结果。
