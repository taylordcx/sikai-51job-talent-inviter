# 演示后核对规则

2026-09-23 的操作记录中，城市弹窗先从已选1项变为2项，点击确定后顶部显示双城；后续操作年限时顶部和条件标签又显示单城。这证明瞬时显示正确不足以判断最终条件正确，但不能仅据此断定是哪一次点击触发了重置。

## 执行顺序与验证

使用 Computer Use（浏览器工具）操作顾问演示所在的人才搜索标签页，不改用另一浏览器的旧会话。先选关联岗位，保留页面随岗位带出的关键词，不重复输入；等待页面更新，再设置其他条件，最后设置期望工作地。

城市弹窗可以通过省份列表选择浙江省，再选择义乌和杭州；如果义乌已选，只补选杭州，不能再次点击取消它。底部已选数为2且标签正好是义乌、杭州才点确定。此路径可替代未能找到唯一城市搜索建议的操作，不使用录制时的屏幕坐标。

完成所有筛选后，核对顶部城市与下方“期望工作地”生效标签，两者均须包含义乌和杭州。等待结果刷新后再次核对；少了城市时重新设置一次并复核，仍回退则停止并说明，不循环点击。搜索提交或选择岗位之后也要复核，不能拿上一次的正确读数继续Hi。

“居住地”是另一组条件：确认后看“当前居住”标签，按[最新默认范围](default-residence.md)或本轮顾问明确覆盖的要求逐项比较。不能把它当作顶部期望工作地；不能将演示中点击的多个城市变成固定默认条件。已有未授权的居住地筛选要清除或先澄清，不能默默继承。

年限看实际生效的“工作年限”标签。学历只有打开下拉、没有选项和生效标签证据时，记为未确认，不能报告已设置。录制中的岗位、关键词、年限和其他可选参数仅是演示输入，不变成未来默认值。仅义乌＋杭州沿用用户明确约定的默认值。

结果刷新后再逐人判断，不以筛选面板已选代替候选人符合。点数以当时页面为准，每次Hi后复核；历史录制中的点数不是当前余额。
